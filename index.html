可調整的內容

修改 map.R 或 config.json 調整範圍、投影與圖層；更換 occurrences.csv 後可直接重跑。

首次先執行 install_packages.R；缺少的高程資料可連網下載並快取。進階圖層與排版差異請見 README.txt。

R 程式碼預覽

先解壓縮製圖包，再以 RStudio／Positron 開啟 map.R，或執行 Rscript map.R。

一次下載程式碼、資料、底圖與套件安裝腳本；首次執行需連網安裝缺少的 R 套件。

FIELD NOTES / 01

從 CSV 到分布圖

  1. 匯入資料：CSV 第一列需是欄位名稱，經緯度使用 WGS84 十進位；支援常見英文及中文欄位。重複紀錄會保留，並納入「樣本數」比例。
  2. 調整樣式：選擇畫面比例或自訂寬高，再調整範圍、地形陰影、圓餅比例與小數位數。座標分組採四捨六入五成雙，與 R 的 round() 相同；它是分格整併，並非半徑搜尋。
  3. 匯出：PNG 為完整圖片；SVG 保留向量點位、界線與文字，地形為點陣；PDF 嵌入高解析度圖片。批次輸出保持相同地圖範圍與完整圖例。
資料來源

街道與步道：OpenStreetMap 貢獻者，資料採 ODbL 授權。圖磚僅供目前視圖；圖檔與 R 製圖包保留來源署名。

RESOLVE Ecoregions 2017 · CC BY 4.0 · 生態圖資來源與概略化方法

全球陸地與國界：Natural Earth Admin 0 Countries 5.1.1，比例尺 1:50,000,000，公共領域資料。小島與局部界線受概略圖資精度限制，名稱與邊界沿用來源資料。

省州界線與名稱：Natural Earth Admin 1，界線 5.1.0、名稱 5.1.1，原始比例尺 1:10,000,000，公共領域資料。已簡化供瀏覽器製圖，並非地籍或即時行政區圖資。

連續海深：Mapzen / AWS Terrain Tiles（海域主要使用 ETOPO1），依負高程逐像素轉成連續藍色，使用 0–11000 m 漸層圖例。局部圖磚需連線讀取；縮放及高解析度匯出不會增加原始測量精度。

海洋與淡水：Natural Earth；等深線採 4.1.0，河流與湖泊採 5.0.0，公共領域資料，原始比例尺 1:10,000,000。海洋地形在 SVG 內為點陣，等深線與河湖保留向量。湖泊未提供水深資料，不適合導航或精確水深查詢。

海拔：Mapzen / AWS Terrain Tiles（Terrarium），依原始 RGB 解碼公尺值。全球色階為 0–9000 m。海域使用對應的陸地界線遮罩，地形陰影於瀏覽器計算。SRTM、GMTED2010 資料由 USGS 提供；ETOPO1：DOC/NOAA/NESDIS/NCEI。

投影可選 Web Mercator（EPSG:3857）、Equal Earth 等面積或 Robinson。比例尺表示地圖中心附近的水平距離，其他位置的比例可能不同。高解析度輸出增加圖檔像素，不會增加 DEM 精度。

物種、配色與符號

取消勾選以篩選；點色塊調整顏色。

每個物種可選 16 種不同輪廓；圖例與匯出同步。共域圓餅維持圓形，自動分配會循環使用 16 種符號。

地圖標示與圖層

行政界線與名稱依圖資涵蓋範圍顯示；名稱於放大後顯示並避開重疊。圖資為概略版本，行政區更動不會即時更新。

座標使用 WGS84；經度 −180° 至 180°、緯度 −85° 至 85°。進階設定可切換全球投影，並將太平洋置中查看跨換日線分布。

極區斜線區域超出目前底圖範圍；85° 邊界是資料截斷線，不是南極海岸線。

Equal Earth 適合比較面積；Robinson 適合全球分布概覽。所有投影都有取捨，局部比例會改變。臺灣模式沿用原有投影。

置中按鈕會切換至全球視角；原有投影會自動改用 Equal Earth。

生物群系底色會取代海拔配色；關閉後回到原有設定。生態區圖資於第一次開啟時載入。

RESOLVE 2017：846 個陸域生態區、14 種生物群系。圖資經概略化，適合區域概覽；不代表現況植被或海洋生態區。

畫面比例

寬、高各 5–60 cm；比例可介於 1:4–4:1。地圖維持正確比例；可拖曳、縮放或按 ↺ 重新定位。

海洋與淡水圖層

詳細河湖資料需同時開啟河流或湖泊；首次載入需要稍候。

全球投影使用概覽資料；Web Mercator 放大後顯示區域細節。

水深漸層或等深線開啟時，自動保留海洋底色。

海深依逐像素高程資料連續配色，範圍為 0–11000 m；可與陸地海拔同時顯示。等深線可另外開關。示範按鈕會替換目前點位及視角。

地形設定

0–9000 m

樣點編號

編號依全部有效資料建立；物種篩選與批次圖共用相同編號。變更座標整併設定會重建編號。

圖層與圖例

點圖上的圖例可開啟工作站，拖曳各圖例可個別調整位置。

大量物種時會自動縮小以容納圖例。圖內圖例可移至留白處避開點位；排版會同步至所有圖檔。

復原與圖框範圍

保留最近 60 步地圖與樣式操作；換資料或欄位後重新開始。Ctrl／⌘ Z 復原，Shift Z 重做（加 Ctrl／⌘）。框內筆數依樣點中心計算，包含重複紀錄及圖例遮住的點。

匯出你的地圖

匯出目前範圍與已勾選物種。圖檔不含網站操作介面；示範資料會加註示範標記。

地形與海深等底圖為嵌入圖片，點位與圖例保留向量；PDF 以圖片儲存。

批次使用目前勾選物種；每張圖維持相同範圍、物種配色與已勾選物種的共用圖例。

樣點對照表

含已勾選物種的全部樣點、座標、物種筆數與來源列；批次 ZIP 也會附上各圖對照表。

完整專案存檔

將全部 CSV 資料、配色、符號、篩選、視角、版面及輸出選項存成一個 .tbm.json；下次開啟即可恢復。檔案包含原始資料，請自行保管。

保留製圖設定

保存範圍、樣式、欄位、配色與符號，不包含原始 CSV；下次先匯入相同資料，再讀取設定。

物種海拔分布

跟隨目前勾選的物種。保留原始值與 DEM 推估值，請依資料來源選擇分析欄位。

DEM 固定以 z12 取樣，不隨地圖縮放改變；格網大小不等於垂直精度。估算需連線，無法取得的點會保留缺值。

獨立樣點依同物種、同座標合併；同點多筆海拔以中位數代表。海拔單位須為公尺。

分帶是自訂視覺背景，不代表通用植群分類。學名斜體沿用樣式面板設定。

街道底圖使用 Web Mercator；地形、水域與行政圖層設定會保留，切回原有底圖即可恢復。

僅載入目前畫面；匯出沿用已載入圖磚，放大輸出不會增加街道細節。地名沿用 OpenStreetMap。

海岸線：OpenStreetMap；河流與湖泊：RiverATLAS／HydroLAKES。細節依資料涵蓋而異，非即時水位。

海深使用 Mapzen／ETOPO1 高程圖磚；近岸及局部精度受原始資料限制。河湖與等深線沿用 Natural Earth 概略圖資。湖泊採統一藍色，不代表湖深。此版不含海溫、鹽度或即時海況。
