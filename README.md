# SPTopo

Browser-based mapping of biological occurrence records worldwide. SPTopo runs as a static site with HTML, CSS and JavaScript. CSV records stay in browser memory.

To run SPTopo locally, run `python3 -m http.server 8000 --directory dist` from the repository root and open http://localhost:8000/.

## Mapping

- Country labels avoid the full text rectangle intersecting Natural Earth 1:10m breakaway/disputed polygons (v5.1.1), with a 2 px clearance. Labels relocate within visible country geometry or are omitted if no candidate fits. This applies in every language and export; it does not change boundaries, occurrence records or quick-location names. Lease and overlay-only features are excluded from the suppression mask. Source coverage is version-dependent, not a guarantee of all current disputes. Rebuild the pinned source with `python scripts/import-disputed-areas.py`.


- **Draw map frame:** choose the rectangle-selection button under aspect ratio, drag across the map and apply. The selected geographic area and page aspect update together; cancel leaves the map unchanged.
- Ocean fill uses the active land geometry as its complement, and country borders use shared interior edges so a separate country coastline is not drawn over the basemap coast.


- The basemap selector adds OpenStreetMap Standard streets and paths alongside the original terrain/ocean map. Street mode uses Web Mercator and temporarily pauses terrain, water, ecology and administrative overlays; their preferences and the original projection return when switching back. Occurrence symbols, legends, graticule, frame, north arrow and scale bar remain available.
- Quick location groups: current records and custom bounds first, then the world, five continents, seven ocean regions and 242 source countries/territories sorted by English name. Ocean regions are overview presets, not maritime boundaries. Automatic or explicit basemap modes. A collapsed Advanced world settings section adds Equal Earth (equal area), Robinson (compromise), Atlantic/Pacific centering, a 14-biome land theme and independent terrestrial ecoregion boundaries. Original Web Mercator remains the default; Taiwan mode retains the original projection. Centering opens the global view and switches Web Mercator to Equal Earth when needed.
- World country boundaries and bilingual country/region labels; optional province/state/prefecture boundaries and names, with adjustable line width. Traditional Chinese names are converted from source Chinese using OpenCC s2twp. Country label placement and size follow the visible country polygon, avoid collisions and prioritize smaller countries. Taiwan retains its detailed county/town layers.
- Global elevation colors and legends span **0–9000 m**; Taiwan mode stays at **0–4000 m**. Every original 0–4000 m color stop is retained. Colors above 4000 m extend through muted brown and gray to white; they are elevation colors, not measured snow cover. Automatic mode selects the scale from the visible basemap.
- Optional marine layers: pale ocean fill, continuous blue bathymetry from decoded Mapzen/ETOPO1 pixel elevations (0–11000 m palette), and independent isobaths. The Natural Earth isobath vectors load only when isobaths are enabled. Major rivers, lakes and reservoirs support freshwater overview maps. Marine/freshwater demonstration buttons replace the current data and view with explicit synthetic examples.
- Default global synthetic example, one-click global/Taiwan examples and downloadable CSVs. These are not biological occurrence records.
- UTF-8 CSV import, automatic/manual column mapping, invalid-row reports, editable group colors and taxon filters.
- 25 per-taxon marker silhouettes (including polygons, directional triangles/arrows, stars, crosses, heart, teardrop, crescent, hourglass, bow tie and chevron), with automatic symbol assignment and matching legends/exports, provide a visual cue beyond color. Multi-taxon co-occurrence pies stay circular. Symbols persist in settings/projects; older settings default to circles.
- Presence/count co-occurrence pies, decimal coordinate merging with ties-to-even rounding, stable optional site IDs and reference tables.
- Client-side hillshade, four DEM quality modes, drag/keyboard navigation, zoom and fit-to-record controls.
- Language selector for Traditional/Simplified Chinese, English, Spanish, French, German, Japanese, Korean, Russian, Arabic and Hindi. Translation covers application menus, all symbol names, layer/layout/export options, legend editor, chart controls and annotations, help/source explanations, placeholders, accessible labels, metadata descriptions, validation errors and dynamic progress messages. Arabic enables right-to-left controls while map/chart axes retain their orientation. Taxon names, source columns, filenames, source-data place names and attribution names remain as supplied. Standard formats, units and technical identifiers such as CSV, DEM and EPSG retain their usual notation. Dictionaries are bundled with no translation API calls or runtime dependency.

Projection/ecology additions are maintained in `dist/locale-world.mjs`, and street-map copy in `dist/locale-basemap.mjs`, with the same complete-language coverage checks. Additional-language copy is maintained in `scripts/locale-keys.json` and `scripts/locale-additions.tsv` (fixed columns: index, es, fr, de, ja, ko, ru, ar, hi). Run `node scripts/build-locales.mjs` after edits to generate `dist/locale-extended.mjs`. The coverage test requires every application string/template in every language dictionary and identical interpolation placeholders; new untranslated copy fails the check. Simplified Chinese is a generated Traditional-to-Simplified conversion dictionary. Translation coverage does not replace review of terminology by native speakers. Geographic labels follow the source dataset’s available names rather than translating research data.

## Coastline and inland-water detail

The terrain basemap automatically uses prepared OpenStreetMap coastline-derived polygons for the land and ocean masks, with separate coastline lines. The optional detailed river and lake switch is under Style → Marine and freshwater layers → Geographic detail. Source grid cuts are never used as coastline strokes. Existing country/county/town polygons contribute shared internal boundary segments in this mode, so their old shoreline outlines do not cover the new coast. Administrative geometry and names remain generalized and can differ from the new shore. Biome/ecoregion rendering is clipped to the same land mask.

Detailed river and lake data replaces the original freshwater vectors when Rivers and/or Lakes are enabled. It uses a cartographic subset of RiverATLAS v1 (CC BY 4.0; Linke et al., 2019) and HydroLAKES v1 (CC BY 4.0; Messager et al., 2016). Whole lakes keep large islands/holes and are deduplicated across intersecting tiles, avoiding artificial grid-edge outlines. Smaller features and small lake islands are omitted at the documented display thresholds. Taiwan source features are retained more finely. Lake color remains uniform and does not represent water depth or current water level. The original Natural Earth freshwater dataset's Taiwan omission applies only when this option is off.

Data is served from the Site itself: no public Overpass backend or live global GIS query. Web Mercator views at zoom 5 and above load intersecting regional chunks, with at most three requests at once; zoomed-out, Equal Earth/Robinson and views needing more than 24 chunks use global overview geometry. Old unstarted requests are discarded and decoded file caches are bounded. Loading/failure blocks incomplete exports; Reload retries failed data. Exports reuse the same geographic detail plan independently of pixel dimensions. PNG/SVG/PDF and R's standalone basemap retain source credits even with all legends hidden; footer space is reserved independently of map and legend typography.

Coast data covers ±85°, uses global 0.005° and Taiwan-vicinity 0.0001° simplification, and has a coarser global overview. These tolerances describe cartographic processing, not positional accuracy. Coastal islands are filtered at recorded size thresholds. It is not a uniform-resolution, exhaustive inventory of all streams, ponds or coast details. The prepared hydro detail retains global river reaches with upstream area ≥10000 km² or average discharge ≥100 m³/s, and lakes ≥50 km², plus additional source rivers/lakes intersecting the documented Taiwan box. Its overview selects larger rivers and lakes ≥250 km². This is a display subset rather than an exhaustive local freshwater inventory. Exact source hashes, filtering, simplification, coverage and citations are recorded in `dist/assets/coast-detail/{index.json,SOURCES.txt}` and `dist/assets/hydro-detail/{index.json,SOURCES.txt}`. Rebuild using `scripts/prepare-coast-detail.py` and `scripts/prepare-hydro-detail.py` with the documented source downloads.

## OpenStreetMap streets and paths

OSM Standard tiles load directly from `https://tile.openstreetmap.org/{z}/{x}/{y}.png` for the current viewport only, with at most four simultaneous requests and 48 tiles per view. Unstarted requests for an old view are discarded; dragging does not initiate tile requests. Normal browser HTTP caching is retained, with a bounded cache of decoded images. The browser sends its normal User-Agent and the site-origin Referer. There is no proxy, cache-busting, prefetch or offline tile archive. Failed or CORS-incompatible tiles block the required export and can be retried using Reload.

PNG, SVG, PDF and the complete R package reuse already-viewed tiles at the same zoom; increasing export size does not fetch more detailed tiles. The R package includes one fixed-view basemap image, not a tile collection. Visible attribution and the full copyright URL are retained in all outputs, including `basemap.png` and R output with legends disabled. The footer reserves space for attribution independently of the legend controls. Map names and the street style follow OSM; application-language changes do not translate those raster labels. OSM requires internet access and the upstream public tile service has no availability guarantee. See `THIRD_PARTY_NOTICES.md` for source and policy links.

## Elevation distributions

The Elevation distribution tab follows the selected taxa and retains the same colors, symbols and display-name aliases. It draws minimum–maximum whiskers, Q1–Q3 boxes (R type-7 quantiles), median markers, jittered values and sample sizes. Choose a meters-valued original CSV elevation column, explicit DEM estimates, or CSV-first filling of missing values. Zero and negative elevations are valid; blank, nonnumeric or values outside −12000 to 10000 m are missing. These are elevation values, not inferred water depth.

DEM sampling runs only on request for selected coordinates using Mapzen/AWS Terrarium pixels at **fixed zoom 12**, independently of the visible map zoom. Up to four tiles load concurrently; exact coordinate results are cached in settings/projects. Source measurements and vertical accuracy vary geographically; pixel grid spacing does not establish vertical accuracy. Missing/failed estimates remain missing and can be retried; source CSV elevations are retained. Comparison CSV includes original, DEM and original-minus-DEM values. No CSV file is uploaded; online sampling requests the required upstream tile URLs.

The default statistical unit merges the same taxon at exactly the same longitude/latitude and uses the median if that site has multiple elevation values. Alternatively count every eligible record. This is separate from rounded map co-occurrence grouping. Custom elevation-band boundaries/labels are visual background aids, not universal vegetation zones. Synthetic elevation-demo data is clearly marked. PNG, editable SVG and raster PDF chart exports use the export panel's image width; comparison and statistical-summary CSVs are available separately. Large datasets subsample displayed jitter points above 6000 eligible values; statistics still use all eligible values. Analysis settings and DEM cache persist in settings and complete projects.

## R map reproduction

The Map R code tab downloads an editable geographic package with `map.R`, `config.json`, selected original WGS84 records, editable taxon styles and palettes, vector layers and decoded DEM tiles. Run `install_packages.R` once, then source `map.R` or run `Rscript map.R`. Change geographic bounds, projection, points, styles or layer settings and rerun. Geographic data are reprojected in R.

The default coastline uses the same OSM-derived land polygons and separate coastline lines as the website. The ZIP contains the current view's coast tiles and a global overview. When the extent changes, R can fetch missing detail tiles from the same source snapshot and cache them locally. To use only packaged data, set `allow_download = FALSE`. Set `coast_detail = FALSE` to use the included generalized land layer. The OSM attribution appears on the rendered map when used, and every R run records its coastline source beside the figure.

PNG, PDF and SVG are saved in a new output directory with run settings and session information. Review `SOURCES.txt` and `export_notes.json` for the initial configuration's data sources and differences from the browser. R recalculates typography, labels and geographic extents. Detailed freshwater, street tiles and biome/ecoregion layers currently differ from the website.

Save edited occurrence and taxon tables as UTF-8 CSV. The R package includes Liberation fonts for accented names and symbols such as ♀, ♂, ± and β. For glyphs outside their coverage, R checks available system fonts. Font attribution and license are included in the package.

## Layout and export

Select a passage in a taxon display name in Legend Studio to make that passage italic or upright. Formatting is saved with settings and projects and follows map and R exports.

Nine page-aspect presets, custom physical dimensions and orientation swapping. Taxon, elevation, depth, river/lake and biome legends have independent switches and draggable positions. Click a legend or the Legend studio button to edit its title, serif/sans/monospace font, text/title sizes, bold/italic styles, text color, background and border. Taxon legends also support columns, row spacing, symbol size and display-name aliases; source records, grouping and site tables retain the original taxon names. Color-bar height is adjustable. Arrow keys nudge each focused legend; Shift moves faster. The floating editor is never exported. Seven original layout presets and sidebar controls remain available. PNG, SVG and PDF use the same render and elevation scale as the preview. SVG keeps vector text, boundaries, markers, contours and river/lake layers with embedded raster land/ocean terrain. PDF embeds a raster image. Per-taxon ZIPs retain one extent, colors and shared selected-taxon legend, with reference CSVs and source notes.

Complete `.tbm.json` projects retain all CSV rows, colors, symbols, legend edits/display names, filters, language, camera, layout and export options. Settings-only JSON is also supported. The existing TaiwanBioTopoMaps configuration/project identifiers remain compatible with previous files.

## Maps across the antimeridian

Web Mercator pans continuously across ±180°. Style → Map extent → Bering Strait frames Russia and Alaska together. For a custom crossing, enter a western longitude greater than the eastern longitude (e.g. west 165°, east −145°). Fit to points chooses the shortest longitude interval; original CSV coordinates remain unchanged. Tile caches use canonical coordinates, and map layers, site counts, coordinate labels and PNG/SVG/PDF/R output share the wrapped view. At global zoom the map displays at most one world. Dataset coverage and local coastline accuracy remain unchanged.

## Data and limits

Natural Earth Admin 0 Countries 5.1.1 at 1:50 million scale provides generalized world geometry. Taiwan retains the Taiwan Atlas 2021.9.20 administrative snapshot, derived from MOI NLSC. Terrain uses Mapzen/AWS Terrarium tiles. Four global z1 tiles and the existing Taiwan z8 tiles are bundled; higher detail requires the upstream service. `prepare_world_assets.mjs` refreshes the global starter tiles; `prepare_assets.py` prepares Taiwan assets. Optional Natural Earth admin-1 data loads once, only when its boundaries or names are enabled. Loading or failure blocks exports that require the layer; Reload retries failures. `prepare_admin1.py --data-dir <cache-directory>` rebuilds the pinned, simplified dataset using pyshp and shapely. See `THIRD_PARTY_NOTICES.md`.

Continuous ocean bathymetry decodes negative elevations in Mapzen/AWS Terrarium tiles (ocean areas primarily use ETOPO1), then interpolates colors between depth stops instead of filling contour bands. Its legend uses the same continuous 0–11000 m palette. Land and ocean reuse the source pixels, with independent bounded color caches. Ocean tile zoom is capped at z8 to avoid implying extra source detail. Pending or failed ocean tiles block required exports even when land elevation is disabled; Reload retries failures. Ocean terrain is embedded raster in SVG, while text, contours, rivers and lakes remain vectors. Bilinear display interpolation and more export pixels do not increase measurement accuracy.

Natural Earth 4.1.0 supplies the ocean mask and optional generalized SRTM Plus contours. Rivers and lakes use Natural Earth 5.0.0. All are Public Domain, originally at 1:10,000,000, simplified and bundled. Lake fill uses the previously selected darker ocean blue uniformly and does not imply lake depth. Ocean fill is implied by bathymetry/contours. These are global/regional cartographic layers, not local hydrographic or navigation data. The river/lake dataset omits Taiwan rivers/lakes and many smaller inland waters; ocean bathymetry around Taiwan is included. Sea temperature, salinity, tides and currents are not provided. `scripts/prepare-water.py <extracted-source-directory>` rebuilds vector assets using pyshp/shapely; source hashes and transformations are in `dist/assets/water-SOURCES.txt`. Marine demo opens with contours off so the continuous surface is visible.

Inputs are WGS84 longitude/latitude; data and extents accept longitude −180° to 180° and latitude −85° to 85°. Web Mercator (EPSG:3857) remains the default. Equal Earth and Robinson use a vendored, tree-shaken D3 bundle; source licenses and pinned rebuild commands are in `dist/vendor/geo-LICENSE.txt` and `scripts/build-projections.mjs`. The selected projection is shared by terrain, ocean, boundaries, freshwater vectors, markers, graticules and exports. The geographic camera and central-meridian choice persist in settings/projects. Pacific centering uses 150°E so records on opposite sides of the date line remain adjacent. Pan and zoom retain geographic anchors; moves beyond the projection domain are bounded. Taiwan basemap mode uses Web Mercator.

Projected land/ocean rasters inverse-map output pixels into the Terrarium source grid with bilinear color sampling and a bounded tile halo. Interactive drag uses a smaller raster; export uses a maximum 2000-pixel-wide/2-million-pixel reprojected terrain layer. This bounds memory and does not increase DEM accuracy. Export checks required source tiles and blocks incomplete terrain. Curved graticules and all vector geometry are clipped at the rotated antimeridian and map viewport. Scale bars represent the horizontal scale near the map center, not uniform scale across the globe; all projections have distortion. The Natural Earth and DEM basemap still ends at ±85°: hatched caps mark missing coverage and synthetic closing edges are omitted from coastline/country strokes. No polar coast or elevation is reconstructed.

The optional RESOLVE Ecoregions 2017 theme has 14 dissolved terrestrial biomes; the detailed boundary overlay retains all 846 biological ecoregion IDs plus a separate auxiliary Rock/Ice record. These are generalized ecological potential regions, not current vegetation, marine regions, sampled site classifications or SDM predictions. Biome fill replaces elevation tint while retaining the user's underlying elevation settings. Source colors are muted consistently for the map and legend, and unclassified/rock-and-ice land is neutral gray. The legend lists all 14 classes, with a neutral unclassified key; it has its own visibility and editable typography/position. Simplification can leave small gaps/overlaps between neighboring regions and differences from the Natural Earth coastline. Small disconnected components are omitted while each source ID's largest component is protected. Datasets load only when enabled (about 4.6 MB for biomes, 10.8 MB for ecoregions before compression). Required loading/failure blocks exports; Reload retries failures. Full attribution, CC-BY-4.0 license, source hash and transformations are in `dist/assets/ecoregions-SOURCES.txt`; `scripts/prepare-ecoregions.py` reproduces assets.

Small islands and local boundaries remain limited by generalized data. More output pixels do not add measurement detail. WorldClim, productivity and SDM layers are not part of this version.

### Land contours

Style → Advanced terrain settings includes an independent land-contour switch (off by default) and 100/200/250/500/1000 m intervals. Contours use the current Terrain Tiles DEM, bilinear sampling and marching squares, clipped to the selected land mask. Elevation labels (metres) appear on sufficiently long contours, prioritizing index contours and avoiding nearby labels and sample points. Labels use plain grey text without halos and sparse placement. The same logical geometry is used in the preview, PNG/PDF and vector SVG, and included in the R basemap. DEM coverage is limited to approximately 85° S–85° N; sampling and source resolution limit detail. Settings and projects preserve both controls; legacy files default to off. OSM pauses these overlays without discarding preferences.
